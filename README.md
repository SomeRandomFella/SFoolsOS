# SFoolsOS

💻 SFoolsOS is a open-sourced browser based, linux style terminal html file, were you can play games, talk in chat and much more! All in one html file. Contribution is welcomed but we do not accept small contributions like readme changes or a small change in a function (and dont contribute slop ai code please 🙏).

# Features

### Games

SFoolsOS has a wide varity of game choices that update without needing to reinstall the file!

### Chat

SFoolsOS has a minimilistic chat system were users can join chatrooms all in one html file!

# Usage

#### All commands

| command | args    | Description                |
| :-------| :-------| :------------------------- |
| `help` | `<command>` | see all commands or get help on a certain one|
| `cd` | `<dir>` | cd into a directory to do certain commands or check files there |
| `ls` | `<page>` | see all files in a directory or check through pages of files|
| `cloak` | `none` | cloak the tab to appear as google drive|
| `game` | `<id>` | open a HTML5 game by using its id|
| `cat` | `<file>` | open text files|
| `clear` | `none` | clear the terminal|

### Chat

| command | args    | Description                |
| :-------| :-------| :------------------------- |
| `chat` | `<roomid> <username>` |join or create a chatroom with a roomid and set ur username|
